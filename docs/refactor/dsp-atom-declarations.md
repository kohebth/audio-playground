# DSP Atom Declaration Audit

## Authoritative List

`APG_ATOM_DEFINITIONS` is the declaration source of truth for all 69 atoms. The same list already drives registry rows
and runtime thunk definitions. `dsp_atoms.h` now expands it through dispatch-aware declaration macros instead of
maintaining a separate handwritten process declaration block.

The dispatch mapping preserves the existing function types:

- `PROCESS`, `WINDOW`, `OVERLAP_ADD`, and `OVERLAP_SAVE` primary functions take `const apg_process_info_t *`;
- `FFT`, `IFFT`, and `MULTIPLY` primary functions take `const apg_spectral_info_t *`;
- `WINDOW`, `OVERLAP_ADD`, and `OVERLAP_SAVE` also declare their existing `*_spectral_process` variants with
  `const apg_spectral_info_t *`.

No parameter gains `const`, and no symbol is renamed.

## Symbol Set

The pre-change and post-change public atom declaration sets both contain:

| API | Symbols |
|---|---:|
| Legacy `atom_name(...)` | 69 |
| Primary `atom_name_process(...)` | 69 |
| Additional spectral variants | 3 |
| Total declarations linked by the ABI test | 141 |

The three additional variants are `freq_window_spectral_process`, `freq_overlap_add_spectral_process`, and
`freq_overlap_save_spectral_process`. Registry thunk symbols remain generated by `atom_thunk.c` and are not part of
the `dsp_atoms.h` function API.

## Enforcement

`test/abi/dsp_atom_symbols.c` expands the canonical list into exact typed function-pointer references. Its dispatch
macros independently select frame or spectral signatures and reference all three additional spectral variants. The
test must compile with `-Wall -Wextra -Wpedantic -Werror` and link against `apgcore`, so a missing symbol or declaration
type mismatch fails the build. It is included in both the `types` and `v2` CTest labels and in `check_v2`.
