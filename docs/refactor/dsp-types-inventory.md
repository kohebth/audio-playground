## Include and Usage Inventory

Production code includes `<atom/dsp_types.h>` directly from the runtime and measure modules. Tests include it directly
from registry, runtime, and measure coverage. `<atom/dsp_atoms.h>` includes it using the current relative public path.
The CLI writes the umbrella include into generated WASM and M7 bundle sources. These paths make retaining the umbrella
mandatory.

`Signal`, `Spectrum`, `Buffer`, and the seven generic port typedefs have no consumers outside `dsp_types.h` at the
baseline. They must still be preserved as public names.

Layout-sensitive consumers are:

- `src/rte/atom_register.c`, which records `sizeof` for all four atom type groups;
- family field-descriptor sources, which use `offsetof` for input, parameter, and state fields;
- registry/runtime storage planning, which allocates and zeroes typed config/state storage by registered size;
- runtime tests, which cast config/state storage back to public atom types;
- numerous tests that use designated initializers and therefore depend on existing field names.

Searches found no raw file/network serialization of atom parameter or state structures, no atom-structure tags or
forward declarations, and no arrays or pointer arithmetic over empty atom types.

## Discovered Risks

1. Forty-six generated empty structures use a GNU extension. The registry observes size 0, while registry/runtime arena
   helpers already reserve at least one byte for zero-size storage.
2. `freq_quantize_params_t` and `freq_quantize_state_t` each contain a public `float unused` field, but the canonical
   catalog reports zero config and state fields. This pre-existing catalog/type mismatch must not be silently changed by
   the mechanical split.
3. The canonical coverage assertion compares only row counts. The baseline set comparison found equal atom names, but a
   future same-count substitution would evade that assertion.
4. Pointer-containing state/config layouts are host-width dependent. The baseline CSV is explicitly LP64 and must not be
   applied as an unconditional 32-bit ABI expectation.
5. Buffer pointer ownership and mutability are implicit in field names and descriptors; the mechanical split will
   preserve them and document ownership later rather than changing qualifiers.

## Reproduction

Generate and run the snapshot without linking the DSP implementation:

```sh
perl tools/generate_dsp_types_abi_snapshot.pl \
    test/abi/dsp_types_abi_snapshot.c \
    inc/atom/types/dsp_type_macros.h \
    inc/atom/types/*_types.h
cc -std=c11 -Iinc test/abi/dsp_types_abi_snapshot.c -o build/dsp_types_abi_snapshot
./build/dsp_types_abi_snapshot test/abi/dsp_types_abi_baseline_lp64.csv
```

The generator sorts atom names, so the same probe is produced from the pre-split umbrella or the category headers.
